# Educ - Advanced Education Platform

A feature-rich education website built using **HTML5**, **CSS3**, and **JavaScript** with advanced interactive features, dark mode, real-time search, animated counters, and comprehensive form validation.

## 🚀 Advanced Features

### 🎨 HTML5
- Semantic HTML5 structure (`<section>`, `<header>`, `<nav>`, `<article>`, `<footer>`)
- Accessibility-first design with ARIA labels
- Optimized content hierarchy for SEO
- Multiple sections: Hero, Courses, Features, Resources, Testimonials, Contact
- Newsletter subscription form
- Enhanced footer with social links and site map

### 💎 CSS3
- **CSS Variables** for theming (Light & Dark mode)
- Advanced Flexbox and Grid layouts
- Smooth animations and transitions
- Glassmorphism effects on search box
- Card-based UI with hover transforms
- Progress bars with gradient fills
- Responsive design (mobile, tablet, desktop)
- Custom scrollbar styling
- Gradient backgrounds and overlays
- Badge components for course levels

### ⚡ JavaScript
- **Dark/Light Theme Toggle** with localStorage persistence
- **Real-time Search** with debouncing for course filtering
- **Animated Counter** for hero statistics using Intersection Observer
- **Advanced Form Validation** with real-time feedback
- **Course Filtering System** with smooth animations
- **Enrollment System** with progress tracking
- **Newsletter Subscription** handler
- **Scroll-to-top** button with smooth animations
- **Notification System** for user feedback
- **Keyboard Shortcuts** (Ctrl+K for search, Ctrl+D for dark mode)
- **Mobile Navigation** with hamburger menu
- **Intersection Observer** for scroll animations
- **Performance Monitoring** in console

## 🚀 How to Run

1. Clone or download this repository
2. Open `index.html` in your web browser
3. No build process, dependencies, or server required!
4. Start exploring the features:
   - Toggle dark mode with the 🌙 button
   - Search courses using the search bar
   - Filter courses by category
   - Enroll in courses and track progress
   - Submit the contact form
   - Subscribe to the newsletter

## ⌨️ Keyboard Shortcuts

- `Ctrl/Cmd + K` - Focus search input
- `Ctrl/Cmd + D` - Toggle dark/light mode
- `Esc` - Close mobile menu
