# Educ - Education Platform

A simple education website built using **HTML5**, **CSS3**, and **JavaScript** to help students access learning resources through a clean, responsive interface.

## Features

### HTML5
- Semantic elements (`<section>`, `<header>`, `<nav>`, `<article>`)
- Proper structure for accessibility and SEO
- Well-organized content hierarchy

### CSS3
- Flexbox layouts for responsive design
- Smooth transitions and hover effects
- Mobile-first responsive styling
- Card-based UI components
- Gradient backgrounds and modern aesthetics

### JavaScript
- Dynamic navigation with mobile menu toggle
- DOM manipulation for content updates
- Form validation with real-time feedback
- Course filtering system
- Smooth scrolling navigation
- Interactive buttons and user feedback

## Project Structure

```
educ/
├── index.html       # Main HTML file
├── styles.css       # CSS styling
├── script.js        # JavaScript functionality
└── README.md        # Project documentation
```

## How to Run

1. Clone or download this repository
2. Open `index.html` in your web browser
3. No build process or dependencies required!

## Technologies Used

- **HTML5** - Structure and content
- **CSS3** - Styling and layout
- **JavaScript** - Interactivity and dynamic features
